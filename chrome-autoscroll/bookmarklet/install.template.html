Auto Scroll

Hands-free scrolling on your phone or any browser, using a bookmark.

📱 Phone: Chrome, Samsung Internet, Edge, Safari

  1. Tap Copy code below.
  2. Bookmark this page (⋮ → ☆), then edit the bookmark.
  3. Rename it to autoscroll and paste the copied code over the URL. Save.
  4. On any page, tap the address bar, type autoscroll and tap the bookmark in the suggestions (the one showing a star).

⇩ Auto Scroll

On a computer the Chrome extension has more options. See the README.

Using it

  • A control bar appears at the bottom right: ▼/▲ direction, − / + speed, ❚❚ pause, ✕ stop.
  • Swiping the page pauses it for a moment, then it carries on.
  • Open the bookmark again to stop it. Your speed is remembered for each site.

Some sites with strict security settings block bookmarks like this one. If nothing happens on a site, that's why.
